# PageFolio を使い始める

配布フォルダー（標準名 `PageFolio-v1.10.2`）全体を作業用の別フォルダーへコピーしてから、`PageFolio.exe` を起動してください。配布元は直接起動せず、そのまま保管します。`PageFolio.exe` と `_internal` は同じ階層に置いたままにします。
ビルドの照合成功は実機受入や出荷承認を意味しません。

## プロンプトを使う

必要な方だけ、EXEと同じフォルダーへ次の名前でコピーします。

| 用途 | コピー元 | コピー後の名前 |
| --- | --- | --- |
| OCR | `ocr_custom_prompt_sample.md` | `ocr_custom_prompt.md` |
| サマリ | `ocr_summary_prompt_sample.md` | `ocr_summary_prompt.md` |

コピー先に同名ファイルがあれば停止し、両方の内容を確認してください。自動で上書きしない運用で、元のサンプルも保持します。
コピーした実利用ファイルを外部のテキストエディタで編集してください。サンプルそのものは編集しません。
LLM設定の「適用（Apply）」では、実利用ファイルが存在する場合、その入力欄の内容がファイルへ書き戻されます。

## 新しい版へ更新する

1. 新しい版を、旧フォルダーとは別の `PageFolio-<版>` フォルダーへ展開します。旧フォルダーは削除せず残します。
2. 旧フォルダーから `pagefolio_settings.json` と、実利用の `ocr_custom_prompt.md` / `ocr_summary_prompt.md` だけを新しいフォルダーへコピーします。
3. 新しいフォルダーに同名ファイルがあれば、コピーを止めます。新旧の両方を残したまま内容を比べ、どちらを使うかを自分で選びます。選ぶまでは何も上書きしません。
4. プラグインは自動では移行されません。旧フォルダーを残したまま、ソースの `docs/PLUGINS.md` にある導入手順で新しいフォルダーへ入れ直してください。
5. 問題が起きたら、旧フォルダーの `PageFolio.exe` を起動すれば元の版へ戻れます。

## 保証範囲

- 今回のリリース保証は、Windowsの単一ログインセッションで利用する環境に限定します。複数ログインセッションを同時使用する環境は保証対象外です。別セッション各1画面・同セッションへの復帰・元状態維持は未確認です。
- 起動排他と既存画面への復帰は、排他に対応した版同士が同じ session で起動された場合が対象です。
- 排他未対応の旧版との同時起動、およびOSによる強制的な前面化の拒否は保証外です。

詳しくは同梱の [設定ガイド](docs/CONFIGURATION.md) を参照してください。
