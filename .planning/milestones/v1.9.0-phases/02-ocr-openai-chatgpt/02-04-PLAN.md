Purpose: 02-03 までで OpenAI の主経路は通っている。ここで残る 4 要件
（V190-OAI-07/08/09/10）を満たし、CONTEXT.md の locked decision（D-13/D-15/D-16/D-17）が
コードに反映されている状態にする。02-REVIEWS.md が指摘した 2 つの HIGH

矛盾する / フォールバックの実機手順が成立しない可能性）は、本プランで構造ごと解消する。

Output: OpenAI 固有欄 4 種の UI と入力検証、フォールバック回帰テスト、
`docs/OCR-PROVIDERS.md` / `docs/CONFIGURATION.md` の追記、3 分割された実機確認の記録。

**バージョン更新はここでは行わない:** `APP_VERSION`・`開発履歴.md`・README バッジの更新は
Phase 1（01-05/01-06/01-07 SUMMARY）で確立した運用に従い Phase 3（V190-QA-03 リリースゲート）へ
委譲する。本プランでは触らない。
