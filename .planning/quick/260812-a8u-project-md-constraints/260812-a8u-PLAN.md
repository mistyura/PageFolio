# Quick Plan 260812-a8u — `.planning/PROJECT.md` に `## Constraints` 節を追加

## 背景

3 プロジェクト比較（260812-9tv）で挙げた差分 #3。loto / numbers はいずれも `.planning/PROJECT.md` に `## Constraints` 節を持ち、
その**末尾行がブランチ運用節への入口**になっている。PageFolio には同節がなく、相当する制約は `CLAUDE.md` に分散していたため、
260812-9tv では入口を暫定的に `## Context` 表へ置いた。

本タスクで `## Constraints` を新設し、入口を loto/numbers と同じ位置（Constraints 末尾）へ移す。

## 原典の構成（numbers `feature/v0.18.0`）

Tech stack / 互換性 / 安全網 / 言語 / 品質ゲート / 禁止 / プロジェクト固有の再検査項目 / ブランチ運用 の 8 項目。
loto も Tech stack / Compatibility / Performance / Code style / Security / ブランチ運用 の 6 項目で同型。
→ **項目名は各プロジェクトの実情に合わせてよく、末尾がブランチ運用ポインタである点が共通の型。**

## 確定事項

1. 記載内容は **`CLAUDE.md` に既にある制約の要約**とし、新しい制約を発明しない
2. `## Context` 表に置いた暫定のブランチ運用行は **Constraints 末尾へ移動**（重複させない）
3. 挿入位置は `## Context` の直後（`## Problem Statement` の前）。loto/numbers の Context → Constraints 順に合わせる
4. 重複を避けるため、詳細は `CLAUDE.md` の該当節を参照させる形にする
