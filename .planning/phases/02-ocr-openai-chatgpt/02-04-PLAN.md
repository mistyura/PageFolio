(1) `sections.py` の OpenAI セクションに、モデル更新ボタン行の**前**へ 3 ブロックを追加する。
いずれも既存 Claude / Gemini セクションと同じ「`tk.Frame` の 1 行 + `width=20, anchor="w"` の
`tk.Label` + 入力ウィジェット」構成で、色は `C[...]`、フォントは `self._font(-1)` /
`self._font(-2)` を使う。

  a. detail 行（V190-OAI-08・D-16）— ラベルは新規 LANG キー `llm_openai_detail_label`。
     `self.openai_detail_var = tk.StringVar(value=self.current_settings.get("openai_detail", "high"))`、
     `self.openai_detail_combo = ttk.Combobox(..., state="readonly", values=("low", "high", "auto"), width=10)`。
     直下に `llm_openai_detail_hint`（`fg=C["TEXT_SUB"]`, `font=self._font(-2)`, `wraplength=460`）で
     「high は読み取り精度優先・low はコスト優先」の趣旨を 1 行で示す。
  b. reasoning effort フレーム（V190-OAI-09・D-15）— `self.openai_effort_frame = tk.Frame(self.openai_section_frame, bg=C["BG_DARK"])`
     を作り、その中にラベル（`llm_openai_effort_label`）と
     `self.openai_effort_var = tk.StringVar(value=self.current_settings.get("openai_reasoning_effort", ""))`、
     `self.openai_effort_combo = ttk.Combobox(..., values=_OPENAI_REASONING_EFFORT_VALUES, width=12)` を置く。
     `state="readonly"` にはしない（RESEARCH.md Open Question 2 のとおり値域がモデル世代で
     変わり得るため自由入力も許す）。**Claude の `self.effort_frame` / `ocr_effort` /
     `_EFFORT_VALUES` は一切流用しない**（D-15。意味論と値域が別物で、片方の変更が他方を壊す）。
     このフレームはここで `pack` せず、表示制御は (3) の `_on_openai_model_change` に任せる。
  c. organization / project 行（V190-OAI-10・D-17）— それぞれ 1 行ずつ、ラベルは

     `tk.Entry(..., bg=C["BG_CARD"], fg=C["TEXT_MAIN"], insertbackground=C["TEXT_MAIN"], relief="flat")`。

(2) `dialog.py` のモジュールレベルへ 2 つのタプルと 1 つの純関数を追加する。
`_OPENAI_DETAIL_VALUES = ("low", "high", "auto")`。
`_OPENAI_REASONING_EFFORT_VALUES` は RESEARCH.md Open Question 2 が挙げた値
（空文字 + `none` / `minimal` / `low` / `medium` / `high` / `xhigh` / `max`）を候補として並べる。
`_sanitize_openai_id(value)` は `str(value).strip()` したうえで英数字・`-`・`_` 以外を含む場合に
空文字を返す純関数（部分的に文字を落とすと別 ID になり得るため、不正なら丸ごと空にして
「ヘッダを付けない」安全側に倒す）。既存 `_EFFORT_VALUES` は変更しない。

(3) `dialog.py` の `_on_openai_model_change` を拡張する。
`is_reasoning_model(self.openai_model_var.get())` が真のとき
`self.openai_effort_frame.pack(fill="x", padx=0, pady=2)` を行い `temperature_frame` を

`pack(fill="x", padx=24, pady=2, before=self.scale_row)` する。Claude 専用の
`self.effort_frame` は openai 経路では常に `pack_forget()`。末尾で `self._resize_to_fit()`。

`_on_provider_change` の openai 以外の全分岐で `self.openai_effort_frame.pack_forget()` も
