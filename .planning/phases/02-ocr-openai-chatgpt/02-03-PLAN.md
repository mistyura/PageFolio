<objective>
LLM 設定ダイアログで OpenAI(ChatGPT) をプロバイダとして選択できるようにし、セッション限定
API キーの入力欄とモデル一覧取得（API 取得 + ヒューリスティックフィルタ + 静的フォールバック）を
提供する。あわせて `sections.py` に残っていたプロバイダ一覧リテラル 2 箇所を catalog 化し、
D-03 の 6 参照面移行を完走させる。

Purpose: 02-02 で送信先確認・コスト確認・APIキー欠落ゲートが openai に対応したので、
ここで初めて openai をユーザーが選択できる状態にしても安全境界が空かない。
このプランの完了で「ユーザーが OpenAI を選び、キーを入れ、モデルを選び、OCR を実行して
確認ダイアログを経て結果を得る」という主経路が通る。

Output: `openai_provider.list_models` + `filter_chat_models` 純関数、`sections.py` の
OpenAI セクションと一覧 catalog 化、`dialog.py` の openai 分岐と `_apply` 収集、
`model_fetch._refresh_openai_models`、lang ja/en 2 キー、回帰テスト。

**UI 設計契約について（記録）:** 本フェーズは `--skip-ui` で計画されており `-UI-SPEC.md` は存在しない。
UI 安全ゲートは本フェーズを frontend-touching と判定したが、02-PATTERNS.md が OpenAI セクションと
既存 Claude セクション（`sections.py:411-510`）の一致度を「exact」と判定しており、
ウィジェット構成・配置・スタイル規約が既存アナログから決定できるため override した。
新規ウィジェットのスタイルは CLAUDE.md に従う（通常操作は `"TButton"`、フォントは
`self._font(delta)`、色は `C["BG_DARK"]` / `C["BG_CARD"]` / `C["TEXT_MAIN"]` / `C["TEXT_SUB"]` の
テーマ辞書参照。ハードコードした色・フォントサイズは使わない）。
</objective>
